## Cirrus 1.0 · 正式版 / First stable release

Cirrus（卷云）是快速、原生的跨平台 Cloudflare API 客户端。它直接连接 `api.cloudflare.com`，凭据只保存在本机系统钥匙串中。

1.0 是首个正式版本，功能与 0.1.0 一致，此后版本号按语义化版本规则递增。

### 功能
- **5 个平台**：Linux、Windows、macOS、Android、iOS 共用一套代码
- **覆盖全部 API**：常用功能有专门设计的界面，其余接口都可以在 API 控制台里调用，参数表单根据官方 OpenAPI 规范自动生成
- 域名、DNS（全部记录类型、BIND 导入导出、DNSSEC）、SSL/TLS（Origin CA 证书的私钥和 CSR 在本机生成）、WAF 与全部规则阶段、缓存、约 60 项域名设置、分析
- Workers：在线编辑并部署、环境变量与绑定、Secrets、自定义域名、路由、Cron、版本回滚、**实时日志**；Pages
- KV、R2（文件管理器）、D1（SQL 控制台）、Queues、Hyperdrive、Vectorize、Secrets Store
- Zero Trust：Tunnels（公共主机名编辑器，可自动创建 DNS 记录）、Access、Gateway、WARP 设备、网络路由、DLP、DEX
- Workers AI 对话和文生图；成员与角色；API Token 创建向导；审计日志；列表与批量重定向；通知；GraphQL 查询器
- 命令面板（Ctrl/⌘ + K）、深色模式、中英双语、生物识别应用锁

### 相对 0.1.0 的变化
- 版本号升级为 1.0.0
- Windows 安装包和 Linux `.deb` 的主页链接指向新的仓库地址
- 构建流程升级到运行在 Node.js 24 上的 GitHub Actions 版本

### 安装说明
| 平台 | 文件 |
|---|---|
| Windows | `Cirrus-1.0.0-windows-x64-setup.exe`（安装版）或 `-portable.zip`（免安装） |
| macOS | `Cirrus-1.0.0-macos-universal.dmg`（未经公证：首次打开请右键选"打开"） |
| Linux | `.AppImage`、`.deb` 或 `.tar.gz` |
| Android | `Cirrus-1.0.0-android-arm64-v8a.apk`（多数手机）或 `-universal.apk` |
| iOS | `Cirrus-1.0.0-ios-unsigned.ipa`（需要侧载安装） |

> 所有接口调用都按照官方 OpenAPI 规范实现，并通过了自动化测试。遇到问题欢迎反馈。
> Every request follows the official OpenAPI schema and is covered by automated tests. Please report issues.
